# Khan Academy

**Khan Academy** は「無料の学習サイト／教材プラットフォーム」。
**Khanmigo** は、その上に乗る **AI家庭教師・AI教師助手** です。

| 比較   | Khan Academy      | Khanmigo                 |
| ---- | ----------------- | ------------------------ |
| 正体   | 学習コンテンツのサイト       | AIチャット型の学習支援             |
| 主な役割 | 動画・記事・練習問題で学ぶ     | 対話しながら考え方を導く             |
| 使い方  | 自分で教材を選んで学習       | AIに質問しながら学習              |
| 答え方  | 解説・問題・ヒントが用意されている | すぐ答えを出さず、質問で導く設計         |
| 対象   | 学習者、保護者、教師        | 学習者、保護者、教師               |
| 料金   | 基本無料              | 教師向け無料、保護者・学習者向けは有料プランあり |
| AIか？ | いいえ、主に教材サービス      | はい、生成AIを使う               |

Khan Academyの本体は、数学・科学・歴史・経済・プログラミングなどの**教材ライブラリ**です。公式にも「free, world-class education」というミッションが掲げられています。([カーンアカデミーサポートセンター][1])

一方でKhanmigoは、Khan Academyが作った**AIチューター兼教師支援ツール**です。学習者には1対1の家庭教師のように考え方を促し、教師には授業準備や管理作業を助けるAI助手として設計されています。([カーンアカデミーサポートセンター][2])

重要な違いは、**Khan Academyは「教材」中心、Khanmigoは「対話」中心**という点です。たとえば数学で詰まった場合、Khan Academyでは動画や解説を読む。Khanmigoでは「どこまで分かっている？」「次に何をすればよい？」と対話しながら進める、という違いです。

```text
Khan Academy = 教科書・問題集・授業動画の集合
Khanmigo     = その横にいるAI家庭教師
```

つまり、KhanmigoはKhan Academyの代替ではなく、**Khan Academyをより個別指導っぽく使うためのAI機能**と見るのが正確です。

## Khanmigoとは  
**Khanmigo（カーンミーゴ）** は、非営利教育サービス **Khan Academy** が提供する、教育向けAIチューター／教師支援AIです。

特徴は、普通のChatGPTのように「答えをすぐ出す」のではなく、**家庭教師のように質問しながら、学習者自身に考えさせる**点です。Khan Academy公式も「答えを直接与えるのではなく、学習者が自分で答えにたどり着くよう導く」と説明しています。([Khanmigo][1])

用途は主に3つです。

| 用途       | 内容                               |
| -------- | -------------------------------- |
| 生徒・学習者向け | 数学、科学、コーディング、人文、歴史などを対話形式で学ぶ     |
| 保護者向け    | 子どもの宿題支援、利用履歴確認、見守り              |
| 教師向け     | 授業計画、学習目標、ルーブリック、小テスト、出口チケット作成など |

もともとは **OpenAIのGPT-4を活用した教育AI** として発表されました。OpenAI公式にも、Khanmigoは「生徒向けの仮想チューター、教師向けのクラスルームアシスタント」と説明されています。([OpenAI][2])

料金・提供状況は少し注意が必要です。公式料金ページでは、**教師向けは無料、保護者・学習者向けは月額4ドルまたは年額44ドル** とされています。([Khanmigo][3]) ただし、公式FAQでは保護者・学習者として使う場合は「18歳以上、米国在住、米国の請求先住所」が必要と記載されています。一方、教師向け Khanmigo は180以上の国・地域で提供対象が広がっているとKhan Academyブログが説明しています。([Khanmigo][1])

要するに、**Khanmigoは“教育用に制御されたChatGPT系AI”**です。
特に良い点は、答えの丸写しではなく、**ソクラテス式に考えさせる設計**になっているところです。学習補助としてはかなり筋が良い方向性だと思います。

## Q: Khan Academyに日本の英語教育に活用できそうなものはありますか？
はい、**あります**。ただし、日本の英語教育で使うなら、Khan Academyは「英会話教材」というより、**英語で読む・英語で考える教材**として使うのが向いています。

## 活用しやすい教材

| 分野          | Khan Academy側の教材                        | 日本の英語教育での使い方                                                                                                   |
| ----------- | --------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 英文法         | **Grammar**                             | 中学〜高校文法の英語説明版として使える。品詞、文構造、句読法などの整理に向く。Khan AcademyのGrammarは「英語を初めて学ぶ人や改善したい人」向けと説明されています。([カーンアカデミー][1])      |
| 読解・語彙       | **ELA practice / Reading & vocabulary** | 米国小中学生向けの読解問題として使える。日本の中高生には「やさしめの本物英語」として有効。ELA practiceは2〜9年生向けで、読解と語彙を扱います。([カーンアカデミー][2])                  |
| 大学入試上位・留学準備 | **SAT Reading and Writing**             | 英検準1級〜1級、共通テスト高得点層、海外大志望者向け。Khan AcademyはCollege Boardと提携した公式SAT Reading and Writing対策を提供しています。([カーンアカデミー][3]) |
| 小学生・初級者     | **Khan Academy Kids**                   | フォニックス、英語絵本、読み聞かせ、初期リーディングに使える。2〜8歳向けで、フォニックス、読み書き、インタラクティブ絵本などを含むとされています。([Google Play][4])                   |
| CLIL的学習     | 数学・科学・歴史などの英語動画                         | 「英語を学ぶ」ではなく「英語で理科・数学を学ぶ」用途に向く。英語上級者にはかなり良い。                                                                    |

## 特に日本で使いやすいのはこれです

**1位：Grammar**
日本の文法学習と相性が良いです。日本の参考書で文法を理解したあと、Khan Academyの英語説明で確認すると、英語で文法用語に慣れます。

**2位：ELA practice**
これは日本人にはかなり良いです。米国の小中学生向けなので、英文は自然ですが、難しすぎません。日本の「受験英語」よりも、語彙・文脈・読解力を鍛える方向です。

**3位：SAT Reading and Writing**
これは上級者向けです。共通テスト対策というより、英検準1級以上、TOEFL、IELTS、海外大学進学に近い領域です。

## 注意点

最大の注意点は、**日本語版は英語教育教材としてはまだ限定的**という点です。Khan Academy公式ヘルプでは、日本語サイトは「Demo sites」に分類されており、完全版ではなく一部コンテンツの翻訳・機能提供という位置づけです。([カーンアカデミーサポートセンター][5])

そのため、日本の学校英語に使うなら、こう考えるのが現実的です。

```text
日本の教科書・参考書
    ↓ 基本文法と試験範囲を押さえる
Khan Academy Grammar / ELA
    ↓ 英語で読んで理解する練習
英検・共通テスト・SAT系問題
    ↓ 実戦力へ
```

## 結論

**日本の英語教育に十分使えます。**
ただし、主教材というより、**副教材・発展教材・多読教材・英語で学ぶ教材**として使うのが良いです。

特に中高生なら、

**日本語で文法理解 → Khan Academy Grammarで英語説明に慣れる → ELAで読解 → SAT Reading and Writingで上級演習**

という流れが一番きれいです。
